# Weather data (not included)

The model uses the **TMYx typical meteorological year for Pune, India (WMO station 430630)**, version 2011-2025,
from climate.onebuilding.org (Lawrie & Crawley). The files are free to download but are not redistributed here.

1. Go to https://climate.onebuilding.org
2. WMO Region 2 - Asia -> India -> Maharashtra
3. Download `IND_MH_Pune.430630_TMYx.2011-2025.zip` (and, for the robustness check, the 2004-2018, 2007-2021 and
   2009-2023 versions)
4. Unzip each into its own folder here, e.g.
   `data/weather/IND_MH_Pune.430630_TMYx.2011-2025/IND_MH_Pune.430630_TMYx.2011-2025.epw`
