# Licence for data, results, figures and documentation

The result files (`results/`), figures (`figures/`), documentation (`docs/`) and the data files compiled by the
authors (`data/*.csv`, `validation/data/*.csv`) are released under the
**Creative Commons Attribution 4.0 International licence (CC BY 4.0)**:
https://creativecommons.org/licenses/by/4.0/

The underlying public sources keep their own terms; each is cited in `docs/DATA_SOURCES.md`:
- toll counts: Maharashtra State Road Development Corporation (MSRDC) monthly fee statements;
- hourly traffic profile: UPEIDA, Ganga Expressway traffic study;
- coupler measurements: Ibrahim & Mohammed, *Batteries* 11(7):257, 2025 (CC BY), values read from its figures;
- weather: TMYx files from climate.onebuilding.org (not redistributed here; see `data/weather/README.md`).

The source code is released under the MIT licence (`LICENSE`).
